# revelrita

Website for revelrita.com. Next.js + Tailwind, deployed on Vercel.

## Run it locally

```bash
npm install
cp .env.example .env.local   # RESEND_API_KEY for email; ADMIN_PASSWORD + KV_* for /admin proposals
npm run dev
```

Then open http://localhost:3000.

See `CLAUDE.md` for how the project is organized and the styling rules.
